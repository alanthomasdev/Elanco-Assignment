# Country Data Dashboard

This is a React-based frontend built with **Next.js**, styled using **Tailwind CSS**, and tested using **Vitest** and **@testing-library/react**. It fetches and displays country-specific data with filtering options.Project Structure

- 🌐 Responsive UI using Tailwind CSS
- 🔍 Region-based country filtering
- 🧪 Unit testing with Vitest & Testing Library
- ⚡ Optimized with Next.js

- `frontend/`: Contains the code for the frontend (React/Next.js).
- `backend/`: Contains the code for the backend (Node.js/Express).

## Prerequisites

- Node.js (v14.x or higher)
- npm or yarn or pnp

## Installation: 

npm run test


## Run in the local :

  npm run dev

## Testing

npm run test
